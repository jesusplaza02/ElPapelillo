# Documentación del Proyecto — El Papelillo

> TFG presentado ante la **Universidad de Málaga (UMA)**  
> Grado en Ingeniería del Software — Curso 2025/2026

---

## Contenido de esta carpeta

Esta sección contiene la **base teórica y el diseño del sistema "El Papelillo"**, incluyendo todos los artefactos de documentación generados durante el desarrollo del Trabajo de Fin de Grado.

---

## Estructura

```
docs/
├── diagramas/      # Diagramas UML del sistema
├── anexos/         # Manuales de usuario, capturas y material adicional
└── memoria_pdf/    # Versión final del documento del TFG
```

### 📐 `/diagramas`

Contiene los diagramas UML elaborados durante el análisis y diseño del sistema:

- **Diagrama de clases**: Relaciones entre las entidades del dominio (Usuario, Agrupacion, Concurso, etc.).
- **Diagrama de casos de uso**: Funcionalidades del sistema desde la perspectiva del usuario (Administrador, Representante).
- **Diagramas de secuencia**: Flujos de interacción entre componentes para las operaciones principales.

### 📎 `/anexos`

Material complementario al documento principal:

- Manual de instalación y configuración del entorno.
- Manual de usuario de la aplicación.
- Capturas de pantalla de la interfaz y la base de datos.
- Scripts SQL de inicialización (si procede).

### 📄 `/memoria_pdf`

Versión final del documento de la memoria del TFG en formato PDF, tal y como fue presentada al tribunal evaluador de la Universidad de Málaga.

---

## Sobre el proyecto

**El Papelillo** es un sistema web de gestión integral de Concursos de Agrupaciones Carnavalescas, desarrollado con **Java 17** y **Spring Boot 3** como Trabajo de Fin de Grado de la Universidad de Málaga (UMA).

Para más información sobre el sistema, consulta el [README principal](../README.md) del repositorio.
